# Farmácia Online

**Exercício 12 de Engenharia de Software** · Gestão da Tecnologia da Informação (GTI) · FATEC Campinas · 2026

Proposta de um e-commerce de farmácia para consultar medicamentos, enviar receitas para análise farmacêutica, realizar compras e acompanhar entregas. O trabalho reúne a modelagem do sistema, o protótipo de interface, a simulação da Sprint 01 e o plano de testes para a futura implementação.
