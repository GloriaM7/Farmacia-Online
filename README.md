# Farmacia-Online
Projeto acadêmico de desenvolvimento de um sistema de Farmácia Online.

## Sobre o projeto

O Farmácia Online é um projeto acadêmico que propõe o desenvolvimento de um sistema digital para facilitar a busca, compra e acompanhamento de medicamentos, oferecendo praticidade aos clientes e ferramentas de gerenciamento para os profissionais da farmácia.

## Objetivo

Desenvolver a proposta de um sistema de farmácia online, contemplando levantamento de requisitos, modelagem UML, planejamento da interface e gestão de configuração do software.

## Organização do projeto

- **Etapa 01 – Requisitos e UML:** levantamento dos requisitos funcionais e não funcionais, identificação dos atores e diagrama de casos de uso.
- **Etapa 02 – Interface:** proposta visual das telas, estrutura de navegação e protótipo do Anexe arquivos arrastando e soltando, selecionando ou colando.
sistema.
- **Etapa 03 – Gestão de Configuração:** organização dos documentos, controle de versões e gerenciamento dos arquivos do projeto.

## Tecnologias e ferramentas

- GitHub – armazenamento e controle de versões.
- Figma – elaboração do protótipo de interface.
- PlantUML – modelagem de diagramas UML.
- Google Docs – elaboração da documentação.
